# Not İstasyonu — Web + PWA

Bu klasör, Not İstasyonu'nun tek linkle PC ve telefondan kullanılabilen web/PWA sürümüdür.

## Yayınlama

Dosyaları bir HTTPS web hosting'e yükleyin. GitHub Pages, Cloudflare Pages veya benzeri statik hosting kullanılabilir.

Önemli: PWA kurulumu HTTPS (veya localhost) altında çalışır. `index.html` dosyasını doğrudan `file://` ile açmak PWA kurulumunu etkinleştirmez.

## Kullanım

Yayınladıktan sonra tek adresi paylaşmanız yeterlidir. Telefonlarda "Ana Ekrana Ekle / Yükle", masaüstünde Chrome/Edge "Uygulamayı yükle" seçeneği kullanılabilir.
